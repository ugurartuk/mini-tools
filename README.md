# Mini Tools

Bu repo küçük ama faydalı Python ve HTML örneklerinden oluşuyor.  
Amacı: GitHub profilimi doldurmak ve pratik kod parçacıkları paylaşmak. 🚀

## İçindekiler
1. sıcaklık_dönüştürücü.py – Celsius ↔ Fahrenheit dönüşümü
2. sayı_tahmin.py – Bilgisayara karşı sayı tahmin oyunu
3. zaman_goster.py – Şimdiki zamanı gösterir
4. todo_list.html – Basit yapılacaklar listesi (HTML+JS)
5. çarpım_tablosu.py – 1’den 10’a çarpım tablosu
